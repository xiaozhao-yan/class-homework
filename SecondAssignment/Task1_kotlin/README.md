## 四、核心练习内容与收获

本次练习覆盖了 Kotlin 的核心语法点，重点掌握了以下内容：

1.  **基础语法与空安全**
    - 变量声明（`val`/`var`）、类型推断、字符串模板
    - 空安全操作符 `?`、`!!`、`?.`、`?:` 的使用场景
    - 与 Java 相比，Kotlin 如何通过语法层面减少空指针异常

2.  **函数与高阶函数**
    - 函数默认参数、命名参数、单表达式函数
    - Lambda 表达式、高阶函数（如 `map`、`filter`、`reduce`）的使用
    - 函数类型与函数作为参数/返回值的场景

3.  **类与面向对象**
    - 数据类（`data class`）、密封类（`sealed class`）的特性与使用场景
    - 继承、接口实现、抽象类的定义与实现
    - 可见性修饰符（`public`/`private`/`protected`/`internal`）的区别

4.  **集合与扩展函数**
    - 常用集合类型（`List`/`Set`/`Map`）的基础操作
    - 集合的链式调用与函数式编程风格
    - 扩展函数的定义与使用，为现有类添加新方法

5.  **其他特性**
    - 泛型基础、`in`/`out` 型变
    - 枚举类、`when` 表达式的高级用法
    - 协程基础入门，理解 `suspend` 函数的概念
